# Stroop 注意力自适应训练系统

基于 Stroop 效应和最近发展区（ZPD）理论的认知注意力训练 Web 应用。

## 项目简介

本项目将经典 Stroop 实验范式从「一次性测量工具」转变为「长期自适应训练系统」。用户判断屏幕上彩色文字的墨水颜色，忽略字义的干扰——系统根据实时表现自动调节干扰强度和呈现时间，维持用户处于最佳挑战区间。

## 认知科学基础

- **Stroop 效应**（Stroop, 1935）：字义与颜色的冲突揭示自动加工与控制加工的竞争
- **神经机制**：前扣带回（ACC）检测冲突 → 背外侧前额叶（dlPFC）实施认知控制
- **最近发展区**（Vygotsky, 1978）：自适应算法将难度维持在 60%-85% 正确率的「最佳挑战区」

## 功能

| 功能 | 说明 |
|------|------|
| 🎮 Stroop 训练 | 四色（红绿蓝黄）中文字符，键盘 R/G/B/Y 作答 |
| 🧠 自适应调节 | 双维度调节：干扰比例（40-80%）+ 呈现时间（500-2000ms） |
| 📊 数据可视化 | 干扰效应趋势图（含线性回归）、箱线图（一致 vs 不一致）、难度调节轨迹 |
| 📝 满意度问卷 | 5 题 Likert 量表，训练后自动弹出 |
| 💾 本地存储 | localStorage，不上传服务器，保护隐私 |
| 📥 数据导出 | CSV 格式，包含训练数据和问卷反馈 |

## 使用方法

1. 在浏览器中打开 `index.html`
2. 点击「开始训练」，用键盘 R/G/B/Y 键作答
3. 每次训练约 5 分钟，建议每天 1-2 次
4. 完成后可查看趋势图、箱线图和导出数据

## 自适应算法

```
if 连续2组正确率 > 85% → 干扰比例 +5%，呈现时间 -100ms（更难）
if 连续2组正确率 < 60% → 干扰比例 -5%，呈现时间 +100ms（更易）
else → 维持当前难度
```

滞回机制（连续2组确认）防止随机波动导致的错误调节。

## 实验设计

本项目设计了一个包含实验组和对照组的用户研究方案：

- **实验组**（n≈15）：使用自适应难度训练
- **对照组**（n≈15）：使用固定中等难度训练
- **方案**：每天一次，每次约 5 组，持续一周
- **指标**：干扰效应降低率、训练坚持率、主观满意度
